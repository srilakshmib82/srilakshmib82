### 🤖 2. Chatbot Language Understanding Module

A Python-based Natural Language Processing module designed to understand user messages and identify their corresponding intents.

The module processes text inputs and uses machine learning techniques to find the most relevant intent from the available intent data.

**Key Features**

- Accepts and processes user text inputs.
- Uses text preprocessing techniques.
- Converts text into numerical features using TF-IDF.
- Applies cosine similarity to compare user input with available intents.
- Identifies the most relevant intent.
- Uses an intent dataset to organize chatbot responses.
- Integrates the language understanding module with a Flask application.

**Technology Stack**

| Category | Technologies |
|---|---|
| Programming Language | Python |
| Framework | Flask |
| NLP | spaCy |
| Text Processing | TF-IDF |
| Machine Learning | Scikit-learn |
| Similarity Measurement | Cosine Similarity |
